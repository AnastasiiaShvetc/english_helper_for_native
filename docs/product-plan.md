# План приложения «Мой английский»

**Статус:** рабочий план для обсуждения. Кликабельный макет сохранён. Создана первая пробная браузерная версия с демонстрационным уроком. Сервер не подключён. Этот документ фиксирует решения из разговора, а не дословную переписку. При расхождении с исходным ТЗ приоритет имеют более поздние решения пользователя.

## Задача и устройство

Пользователь изучает английский в ChatGPT по скриншотам из учебной программы. В чате разбираются предложения, переводы, слова, устойчивые выражения, грамматика и примеры. Затем пользователь даёт команду о готовности части урока. Практика проходит в отдельном браузерном приложении на телефоне, которое можно добавить значком на главный экран. Telegram для работы приложения не нужен.

Первая версия рассчитана на одного ученика. В дальнейшем можно добавить других, не смешивая их материалы и результаты.

## Передача учебного материала

1. Пользователь присылает подготовленный ChatGPT файл в чат Codex и указывает урок и часть, например: «Добавь в урок 14, часть 1».
2. Codex проверяет весь файл на полноту и явные ошибки. В приложение добавляется **весь** переданный материал, без самостоятельного отбора слов. Нечитаемые или противоречивые фрагменты нельзя молча пропускать.
3. Новый файл дополняет указанный урок; прежние части и результаты сохраняются. Повторная передача одного файла не должна создавать копии.
4. Codex сообщает о фактически подтверждённом результате передачи. Ошибку перевода, примера или правила пользователь сообщает в Codex; исправление не стирает историю ответов.

Исходные скриншоты в приложении хранить не нужно. Нужно различать предложения из исходного урока и примеры, придуманные при разборе. В первой версии пользователь не загружает файл вручную через приложение. Прямую передачу из ChatGPT можно исследовать позже. Связь Codex с работающим приложением ещё нужно создать и проверить на реальном файле.

Одинаковое слово, встретившееся в двух уроках, остаётся в обоих уроках отдельно, с независимым прогрессом.

## Главный экран

- Вверху — небольшие маскоты: рыжий учёный кот в очках и чайка в красной шапочке и шарфе. Их образ повторяется на других экранах.
- Непрерывная серия дней занятий; семь кружков для календарной недели; общее число дней занятий и число выученных слов.
- День занятий засчитывается после **завершённой десятки заданий**. Поясняющую подпись под календарём показывать не нужно.
- Отдельная заметная карточка «Повторение всего» с количеством заданий, подошедших к повторению.
- Карточки уроков; пустой урок автоматически не появляется.
- Раздел «Ваш рост» с тремя краткими показателями: 🌱 выученные за неделю новые слова, ✨ отработанные правила грамматики, ⏱️ суммарное время занятий за неделю. Эмодзи стоят в начале фраз, без дополнительных пояснений под ними.
- Ниже — ярко-оранжевая карточка с котом, чайкой и доброй мотивирующей фразой. Фраза меняется после полуночи по московскому времени. На карточке нет кнопки переключения и подписи «От кота и чайки».
- Доступны «Мой прогресс» и настройки.

Слово считается **выученным**, когда пользователь смог самостоятельно написать и употребить его в предложении. Один правильный выбор перевода этого не означает. Точную формулу показателя нужно проверить на примерах до реализации.

## Урок и виды практики

Урок имеет номер, название и одну или несколько частей. Можно тренировать отдельную часть или весь урок. Любой вид задания доступен сразу, без обязательного прохождения предыдущих. Пропущенный вид не получает прогресс. Внутри урока три блока и восемь видов работы:

| Блок | Вид | Действие |
|---|---|---|
| Слова и выражения | 1.1 Узнавание | Английское слово или выражение → один русский перевод из четырёх вариантов. Неверные варианты правдоподобны, но в данном контексте однозначно неверны. |
| Слова и выражения | 1.2 Воспроизведение | Русский перевод → самостоятельный ввод английского слова или выражения. Проверяются написание, нужные предлоги, артикли и обязательные части. |
| Слова в предложениях | 2.1 Выбор слова | Английское предложение с пропуском → подходящее слово из четырёх вариантов. |
| Слова в предложениях | 2.2 Без подсказки | Заполнение пропуска в английском предложении самостоятельно. |
| Слова в предложениях | 2.3 Перевод | Перевод предложения с русского на английский с целевой лексикой. Допускаются разные верные формулировки. |
| Грамматика | 3.1 Объяснение | Подробное правило на русском: когда применяется, схема, утвердительная/отрицательная/вопросительная формы, несколько примеров, типичные ошибки и важные отличия. Правило можно перечитывать в любой момент; чтение не оценивается как выполненное задание. |
| Грамматика | 3.2 Выбор | Выбор правильной грамматической формы. В обычном тесте один ясный ответ; несколько правильных — только если это прямо сказано в вопросе. |
| Грамматика | 3.3 Перевод | Самостоятельный перевод предложения с применением целевого правила. |

Задания создаются из сохранённых слов и правил урока. Для задания хранятся цель, проверяемый навык, правильный ответ и допустимые варианты, объяснение, сложность, контекст и версия. Примеры не должны бесконечно повторять один шаблон.

## Логика десятки

В выбранном виде задания приложение случайно выбирает **до 10 разных единиц** из оставшихся. На экране один вопрос. Для задания с вариантами проверка начинается сразу по нажатию варианта; кнопку «Проверить» показываем только там, где пользователь печатает ответ. При ошибке выбранный вариант красный, правильный зелёный. После каждого ответа сразу показываются результат и объяснение. Формулировка правильного ответа: «Верно: …».

- Правильный ответ **с первой попытки** убирает задание из обычной тренировки только по этому виду навыка и переносит его в повторение.
- Если была ошибка, задание остаётся в обычной тренировке. Исправление после подсказки в том же заходе не засчитывается как самостоятельный успех.
- Например, из 50 слов случайно выбраны 10; 8 ответов правильные с первой попытки, 2 с ошибкой. В этой тренировке остаётся 42 слова. Когда остаётся меньше 10, показывается столько, сколько есть.
- Можно завершить занятие после каждой десятки или перейти к следующей. Результаты сохраняются после каждого ответа. Экран завершения показывает число правильных ответов с первой попытки и короткую поддерживающую фразу.

Для неправильного ответа показываются: ответ пользователя → правильный ответ → конкретная ошибка → правило или нюанс → дополнительный пример. Грамматические ошибки сопровождаются коротким корректирующим упражнением и сохраняются по типам. Правильный ответ не перегружается подробным объяснением; его можно раскрыть отдельно.

## Свободные переводы и проверка

При проверке написанного предложения важны смысл, орфография, грамматика, целевое выражение/правило, естественность и подходящий стиль. Верные альтернативные переводы принимаются. Если смысл верный, но есть ошибка в грамматике или написании, задание остаётся в тренировке. Если предложение грамотное, но обходит целевое слово или правило, приложение хвалит за грамотность, показывает вариант с учебной целью и оставляет задание в тренировке. Нужна кнопка «Перепроверить ответ» на случай спорной оценки.

**Открытый технический вопрос:** ChatGPT в отдельном чате может подготовить задания заранее, но не видит автоматически новые ответы, введённые пользователем в браузерном приложении. Пользователь не хочет подключать дополнительный платный ИИ. Без отдельной связи приложение может надёжно проверять выбор из вариантов и заранее подготовленные ответы, но не должно выдавать простое сравнение с образцом за полноценную оценку любого свободного перевода. Позже пользователь может отдельно поручить Codex настроить автоматическую проверку свободных переводов и протестировать её на реальных ответах. Возможны отдельный доступ к ИИ или запуск подходящей модели на сервере пользователя; качество и требования к серверу нужно проверить. Подписка на чат ChatGPT сама по себе не даёт приложению доступ к этому чату. Способ проверки нужно согласовать и проверить до заявления о готовности приложения. Никакая оплата или внешняя проверка пока не подключены.

## Повторение всего

Это самостоятельная карточка на главном экране с материалом из разных уроков. Внутри доступны «Пора повторить», «Мои частые ошибки» и «Смешанная тренировка», а также выбор вида задания. Повторение идёт десятками; после каждой можно выйти. Материал возвращается сначала через день, затем через 3 дня, 7 дней, далее через 14–30 дней и реже. Интервалы могут уточняться по результатам использования.

Ошибка при повторении оставляет слово или правило **в повторении**, не возвращая его в обычную тренировку урока. Повторяющиеся ошибки должны влиять на подбор следующих заданий. При повторении меняются примеры и контексты, сохраняя проверяемое слово или правило.

## Персонализация

Для серии новых примеров предложено распределение: 30% — академический английский и медиакоммуникации, 20% — маркетинг, PR и управление, 25% — личная жизнь и интересы, 25% — новые универсальные ситуации. Это ориентир для серии, а не жёсткое распределение каждой десятки; тема исходного урока сохраняется. Гипотетические ситуации допустимы, но их нельзя выдавать за реальные события пользователя.

## Прогресс, дизайн и надёжность

Прогресс отображается отдельно по навыкам, урокам и частям. Доступны история занятий и ответов, трудные выражения, типы грамматических ошибок и рекомендации, что повторить. Процент правильных ответов в коротком тесте нельзя называть общим уровнем владения английским.

Дизайн: тёплая жёлто-оранжевая гамма, мягкие объёмные карточки, крупный текст, один вопрос на экране, спокойная анимация. Образы кота и чайки создают дружелюбный тон. Макет в `prototype/index.html` показывает выбранное направление, но его числа, материалы и проверка ответов демонстрационные.

Рабочая версия должна сохранять результат после каждого ответа и не терять его при закрытии или обновлении страницы. Личные материалы и история доступны только пользователю. Нужны экспорт и восстановление данных, а также защита технических ключей. Приложение предполагается разместить на сервере пользователя; сервер пока не подключали. На GitHub материалы и копию прогресса отправляют только по отдельной команде пользователя. Между такими сохранениями данные работают на сервере и в репозитории не обновляются автоматически.

## Что не входит в текущий макет

Озвучивание, голосовая практика, диалоги с ИИ, академические диалоги и прямая передача материалов из ChatGPT — будущие возможности. Способ напоминаний для браузерного приложения отдельно не выбран. Сервер, общая база данных, проверка произвольных свободных переводов с ИИ и импорт реальных материалов пока не созданы. В пробной версии работают проверки заранее подготовленных ответов и локальное сохранение на одном устройстве.

## Следующий этап

Сначала пользователь просматривает сохранённый макет и план. После прямой команды на создание рабочего приложения можно приступить к реализации и проверке на реальном материале. Сервер подключают отдельно, после получения доступа. Изменения кода, учебных материалов и прогресса на GitHub сохраняются по команде пользователя.
