# Мой английский

Здесь сохранены **план браузерного приложения для изучения английского** и **кликабельный макет**. Это пока не работающее приложение: примерные уроки, цифры и ответы в макете нужны только для обсуждения экранов.

- [Согласованная логика и открытые вопросы](docs/product-plan.md)
- [Макет, который можно открыть в браузере](prototype/index.html)
- [Изображение главного экрана](prototype/home-preview.png)

Чтобы посмотреть макет на своём компьютере: на странице репозитория нажмите **Code → Download ZIP**, распакуйте архив и откройте файл `prototype/index.html` в браузере. Внутри можно нажимать на уроки, виды заданий и варианты ответов. Интернет для просмотра макета не нужен.

Проект в репозитории пока не запускается как приложение на телефоне и не подключён к серверу. Код рабочего приложения, учебные материалы и результаты занятий здесь ещё не сохранялись.
