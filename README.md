# Мой английский

Браузерное приложение для тренировки английского на телефоне. [Открыть приложение](https://anastasiiashvetc.github.io/english_helper_for_native/).

В уроке 14 доступны две части: 111 слов и выражений, 28 грамматических правил, упражнения на лексику и грамматику, повторение и сохранение прогресса в браузере. Материалы для урока хранятся в папке [`materials/`](materials/), само приложение — в [`web/`](web/). [Что работает и какие есть ограничения](web/README.md).

Кликабельный макет раннего дизайна хранится в [`prototype/`](prototype/). План дальнейшего развития — в [`docs/product-plan.md`](docs/product-plan.md).
