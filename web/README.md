# Первая пробная браузерная версия

Это **работающий пробный вариант**, а не макет. В нём только демонстрационный урок 14 с 10 выражениями и двумя правилами. Исходные учебные материалы пользователя сюда ещё не добавлены.

## Как посмотреть

- Если GitHub Pages включён, откройте https://anastasiiashvetc.github.io/english_helper_for_native/.
- Для проверки как сайта запустите из корня репозитория `python3 -m http.server 8000` и откройте `http://127.0.0.1:8000/web/` на этом компьютере.
- Код сайта находится в этой папке: `index.html`, `app.js`, `style.css`, `content.js`, `manifest.webmanifest`, `sw.js` и изображение маскотов.

В опубликованной версии значок на телефоне добавляется из меню браузера.

## Что работает

- выбор урока, части и одного из восьми видов работы;
- случайная подборка до 10 заданий из оставшихся;
- проверка выбора сразу по нажатию, написанного слова — по кнопке;
- перенос правильно выполненного с первой попытки задания в повторение; ошибка оставляет его в тренировке;
- интервалы повторения 1, 3, 7, 14, 30, 60 дней; ошибка в повторении остаётся там;
- сохранение каждого ответа в браузере, счётчики, календарь занятий, фраза поддержки;
- выгрузка и восстановление копии прогресса через экран «Данные»;
- кэширование сайта для повторного открытия без сети после первой загрузки через HTTPS или localhost.

Свободные переводы проверяются только по заранее подготовленным правильным вариантам и известным ошибкам. Неизвестный вариант не считается ни верным, ни ошибочным: приложение сообщает, что нужна проверка. Дополнительный ИИ, сервер и оплата не подключены.

## Важные ограничения выбранного способа

Прогресс хранится **только в браузере конкретного устройства**. Очистка данных браузера или смена телефона может его удалить. Скачанная копия прогресса позволяет восстановить его вручную. Codex не может автоматически забрать прогресс из браузера телефона для сохранения на GitHub; пользователь должен передать выгруженный файл.

Для добавления урока в общую версию сайта Codex обновляет `content.js`, после чего новая версия должна быть отправлена на GitHub. Это действие выполняется только по команде пользователя. На GitHub Pages учебные материалы из файлов сайта будут доступны посетителям опубликованной страницы; личные материалы не следует публиковать без отдельного решения о приватности.

Значения в интерфейсе теперь рассчитываются из ответов, но учебный материал демонстрационный. Работа на конкретном телефоне и установка значка ещё не проверены.
