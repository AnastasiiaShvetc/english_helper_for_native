# Браузерное приложение «Мой английский»

В приложении опубликован урок 14 из двух частей: 111 слов и выражений и 28 грамматических правил. Учебные пакеты сохранены в `materials/lesson-14-part-1.md` и `materials/lesson-14-part-2.md`; файл `content.js` собирается из них командой `python3 scripts/build_content.py` из корня проекта. Предыдущий демонстрационный урок заменён учебным материалом.

Если GitHub Pages включён, приложение открывается по адресу https://anastasiiashvetc.github.io/english_helper_for_native/. На телефоне ссылку можно добавить на главный экран.

Внутри урока можно открыть часть 1, часть 2 или весь урок. Для просмотра слов, примеров и правил выберите «Посмотреть материал». Каждый из восьми видов занятий доступен сразу. Приложение выбирает до десяти заданий из оставшихся в выбранном виде, сохраняет ответы и планирует повторение.

Выбор из вариантов и заранее подготовленные ответы проверяются без сервера. Непредусмотренный свободный перевод помечается «Нужна проверка», а не ошибкой. Живая проверка любого предложения с подробным разбором пока не подключена.

Прогресс сохраняется в браузере. После однократного подключения по личной ссылке результаты автоматически объединяются с вашим сервером и другими подключёнными устройствами. На экране «Данные» виден статус синхронизации; там же можно скачать или добавить резервную копию. Без интернета занятия сохраняются локально и отправляются после восстановления связи. Исходные данные каждого устройства сохраняются отдельно перед первым объединением. Подробнее для администратора: [служба синхронизации](../server/README.md).

GitHub Pages и этот репозиторий доступны публично: учебные пакеты и задания можно прочитать по ссылке. Исходные скриншоты не были приложены к пакетам; точность и полноту исходных фрагментов по ним не проверяли. Некоторые примеры созданы специально для практики и помечены в пакетах.
